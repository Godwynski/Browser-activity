Laboratory Exercise 
Pygame and OpenGL  
Objective: 
 
At the end of the exercise, the students should be able to: 
 
▪ Set up graphics using Pygame and OpenGL. 
Software Requirement: 
 
▪ Python 3.7 or higher 
Procedure: 
 
1. Launch Command Prompt.  
2. You need to install the following packages: 
• Pygame – used for creating windows and handling user input 
• NumPy – used for mathematics and scientific computing 
• PyOpenGL and PyOpenGL_accelerate – provides a set of bindings from Python to OpenGL 
Install all the abo ve packages  by entering  py -m pip install pygame numpy PyOpenGL 
PyOpenGL_accelerate. 
3. Launch IDLE.  
4. Create a Python module by clicking File > New File. 
5. Save your module, then run it by clicking Run > Run Module or by pressing F5. 
6. Type the following to import the packages: 
import pygame 
from pygame.locals import * 
 
from OpenGL.GL import * 
from OpenGL.GLU import * 
7. Initialize the modules of the above packages. Enter the statement, pygame.init(). 
8. To set up your application’s window, type the following statements: 
display = (800, 600) 
pygame.display.set_mode(display, DOUBLEBUF|OPENGL)  
You may adjust the display’s width and height.  The constants, DOUBLEBUF and OPENGL, indicate that 
OpenGL will be used with double buffering. Double buffering means that there are two (2) buffers; one 
buffer is displayed while the other buffer is being drawn.  
9. To set the window’s caption, enter pygame.display.set_caption(“03 Lab 1” ) Indicate your full 
name in the caption. 
10. Use the gluPerspective() command to set  up the viewer’s perspective.  This method has four (4) 
parameters: the field of view angle, aspect ratio, distance from the viewer to the near clipping plane, 
and distance from the viewer to the far cl ipping plane. Objects drawn on the screen may appear too

11. If your application needs to be continuously updated , it must have an event loop. This is where all the 
events occur, and the objects’ states update until you quit your application. Type the following code for 
your initial loop: 
while True: 
    for event in pygame.event.get(): 
        if event.type == pygame.QUIT: 
            pygame.quit() 
            quit() 
    glClear(GL_COLOR_BUFFER_BIT|GL_DEPTH_BUFFER_BIT) 
    pygame.display.flip() 
    pygame.time.wait(15) 
Use the glClear() function to clear the buffers such as color and depth buffer s. Without this, the trail 
of the objects’ movement becomes visible. pygame.display.flip() updates the content of the entire 
display, while pygame.time.wait() is used to pause for a period of time. 
12. Try to draw some vertices on your window.  Copy the following statements  to draw four (4) vertices.
