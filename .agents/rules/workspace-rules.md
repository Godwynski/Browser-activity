# Workspace Rules: Clean Organization & Agent Discipline

## 🎯 Purpose
These rules govern file placement, task organization, and tool execution to ensure zero clutter and consistent structure across all academic coursework, browser automation, and development tasks.

---

## 🏛️ Directory Hierarchy Mandate

All files generated by Antigravity or any subagent MUST adhere to this strict hierarchy:

```
Browser activity/
├── courses/                       # Single source of truth for all coursework
│   └── <Subject_Name>/            # e.g., Computer_Graphics_Programming, IT_Service_Management
│       ├── handouts/              # Downloaded lecture slides, PDFs, notes
│       ├── syllabi/               # Course syllabi, grading policies
│       └── assignments/
│           ├── midterm/
│           │   └── <Module_Name>/ # e.g., 03_Laboratory_Exercise_1
│           │       ├── materials/ # Source PDF handout & prompt
│           │       ├── src/       # Executable code (e.g., wireframe_cube.py)
│           │       ├── answer.md  # Final formatted deliverable for submission
│           │       └── .tmp/      # Temporary extracted text, scratch files (gitignored)
│           └── finals/
├── brave-mcp/                     # Playwright & CDP bridge server
│   └── scripts/
│       ├── cdp/                   # Port 9222 & CDP health checks
│       ├── elms/                  # STI ELMS scrapers & assignment downloaders
│       ├── gdrive/                # Google Drive automation & rclone
│       ├── social/                # Instagram / social automation
│       └── scratch/               # One-off experimental scripts
├── brave-launcher/                # Brave startup & permanent shortcut utilities
├── brave-extension/               # Floating HUD & browser companion
└── artifacts/                     # Ephemeral runtime logs, screenshots & raw data
```

---

## 🚫 Forbidden Practices (Zero Tolerance)
1. **NO Root Dumps**: Never create root folders like `CGP_Midterm_Assignments/` or dump `.txt`, `.py`, `.pdf`, or `.md` files in the project root.
2. **NO Mixed Folders**: Never mix raw extracted text (e.g., `extracted_pdf_text.txt`) or Python `__pycache__` with source code or deliverables.
3. **NO Ad-Hoc Scripts in Root**: All scripts must be housed in `brave-mcp/scripts/<category>/` or within their respective skill directory.
4. **NO Unstructured Assignments**: Every lab exercise, assignment, or performance task must have its own dedicated directory with `materials/`, `src/` (if code exists), and `answer.md`.

---

## ⚙️ Standard Task Execution Protocol
1. **Ingestion**: When fetching an assignment from ELMS, route the PDF directly into `courses/<Subject>/assignments/<term>/<task>/materials/`.
2. **Text Processing**: Any intermediate extraction or OCR goes into `.tmp/` and is deleted or gitignored once processed.
3. **Coding**: Python/C++/JS source files live inside `src/`.
4. **Deliverable**: The solution report or answer sheet is saved as `answer.md` in the module directory.
